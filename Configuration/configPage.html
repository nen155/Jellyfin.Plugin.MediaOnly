Ignorar durante el escaneo cualquier archivo cuya extensión no esté en la lista.

Bibliotecas donde se aplica el filtro

Solo se filtran los archivos dentro de las bibliotecas marcadas. Si no marcas ninguna, el plugin no hace nada.
Ejemplos: mp4, mkv, jpg, png. Añade srt, ass, vtt, nfo… si la biblioteca filtrada también debe conservar subtítulos o metadatos locales.
